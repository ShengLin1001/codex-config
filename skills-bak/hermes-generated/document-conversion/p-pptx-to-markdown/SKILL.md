# PPTX to Markdown

## 核心流程

1. 先记录文件名、页数和输出目录，保留原 PPTX 不变。
2. 按幻灯片顺序提取标题、正文、备注、表格和图片；同页内容保持分组。
3. Markdown 使用稳定页标题和相对资源路径，图片名包含页码与对象序号。
4. 对文本很少的页面渲染预览，确认关键信息是否实际位于图片、图表或公式中。
5. 检查页数、资源引用、空页和乱码，再交付 Markdown 与资源目录。

## 易踩点

- XML 中的文本顺序不一定等于视觉阅读顺序。
- SmartArt、图表、公式和组合对象不能仅靠普通文本提取。
- 不把逐页抽取结果直接当成已经整理好的文章结构。
