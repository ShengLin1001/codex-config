# Manuscript Repository Workflow

## 核心流程

1. 先读仓库规则，确定主源文件、共同权威文件、派生格式、构建产物和只读证据。
2. 只编辑用户授权的源文件；同步 LaTeX、DOCX、PDF、SI 或重新构建必须另有明确授权。
3. 修改前核对相关图、公式、符号和引用；修改后检查目标 diff、链接和 `git diff --check`。
4. 用户中途缩小范围时，立即停止过时工作，重新核对工作树，只保留新范围内的改动。
5. 委派任务以真实文件、验证结果和 Git 状态为完成证据；退出码或自报完成不足以验收。

## 易踩点

- 不假设同名 Markdown、TeX 和 DOCX 都需要同步。
- 不在只要求改文字时自动编译或更新构建产物。
- 不从派生 PDF 反向覆盖主源文件，除非用户明确指定新的权威来源。
- 独立审查保持只读，避免审查过程改变待审对象。
