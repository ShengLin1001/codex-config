# Journal Transfer

## 核心流程

1. 读取稿件摘要、已有评估和拒稿信，提取贡献、已知弱点、前作重叠及拒稿主因。
2. 对每个候选期刊核对当前官方 scope、文章类型、费用和投稿要求；影响因子等易变数据必须现场查询并标日期。
3. 搜索同类方法或主题的已发表先例，判断真实 scope fit，而不是只匹配关键词。
4. 按范围匹配、编辑门槛、补充工作量、重写成本和费用排序，给出主投与后备路线。
5. 明确每个期刊需要改变的叙事重点，以及哪些科学缺口必须先补。

## 易踩点

- scope 不匹配时优先换期刊，不要把稿件硬改成更高门槛的叙事。
- 不用缩写识别期刊；同时核对出版社、全名和 ISSN。
- 不只按影响因子排序，也不把估计接受率写成确定事实。
- 先处理与作者前作的差异化，再讨论包装和措辞。
