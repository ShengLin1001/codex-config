# Agent Work Review

## 核心流程

1. 将每项完成声明映射到可检查的文件、命令输出或数值产物。
2. 确定性结果用逐文件 diff、哈希或逐列数值比较；随机结果先核对 RNG 消耗顺序和容差。
3. 摘要中的每个关键数值必须能从产物重新计算；外部工具语义要回到源码或官方文档确认。
4. 使用比原任务更独立或更丰富的数据复跑关键路径，检查遗漏、污染和不自洽。
5. 输出已验证事实、未证实声明、真正问题、严重度和可执行修复。

## 易踩点

- 列数变化时按列名比较，不按位置索引。
- 行列式绝对值不能单独判断逆矩阵可靠性；检查 `max|A A^-1-I|`。
- Pearson 接近零不等于没有关系；同时检查异常值敏感性和 Spearman。
- 没有计时代码或原始记录时，不接受性能声明。
