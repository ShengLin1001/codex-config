# n2p2 Workflow

## 核心流程

1. 先确认 n2p2 源码语义、输入格式、数据维度和当前项目约束。
2. 用 NumPy 和标准库实现最小路径，先通过合成数据自检，再运行真实端到端样例。
3. 结构选择只在训练候选集中执行；记录随机种子、样本映射和每步选择依据。
4. 若使用行替换或 maxvol，验证 `w_row = v @ A^-1` 的索引方向，并检查 `max|A A^-1-I|`。
5. 评估同时报告 Pearson、Spearman、异常值和实际计时；产物包含可复现命令。

## 易踩点

- 不按列位置假设数据语义，先核对列名和单位。
- 行列式大或小不能单独证明矩阵稳定。
- 不让验证集、测试集或后验挑选结果进入训练候选池。
- 没有计时代码时不声称性能提升。
