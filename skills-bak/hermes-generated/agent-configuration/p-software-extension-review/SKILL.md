# Software Extension Review

## 核心流程

1. 固定软件版本、平台、目标功能和所需文件格式。
2. 核对扩展的准确名称、发布者、标识符、维护状态、权限和安装来源。
3. 先给一个默认选择；只有功能明显互补时再列可选扩展。
4. 安装后用真实文件或最小示例验证打开、编辑、导出和卸载路径。

## 易踩点

- 不依赖搜索摘要或旧榜单中的下载量、评分和兼容性。
- 相近后缀可能不是同一格式，例如 `tif` 与软件声明中的 `tiff` 要实际验证。
- 不同时安装多个功能重叠扩展来“保险”。
