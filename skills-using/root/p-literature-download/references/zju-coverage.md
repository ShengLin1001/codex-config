# 浙大订购空档

`INSTITUTION` 是 `"Zhejiang University"` 时适用；换学校后本表作废。

用法：

- **跑批前**按 DOI 前缀和出版年对表。落在空档里的，先告诉用户「大概率拿不到」，由用户决定保留还是在 DOI 列表里注释掉。**不要自动跳过**：Elsevier open archive 等例外不需要订阅，自动跳过会误杀。
- **跑完失败的**，落在空档里就在报告里写「疑似机构未订购」，不要写成脚本故障，也不要反复重跑。
- 新实测到的无权限案例补进「实测」列（DOI + 日期）。

年限摘自浙大图书馆数据库导航 `https://libdb.zju.edu.cn/s/lib/libtb/show/<id>` 的「访问内容年限」，读取于 2026-11-13。页面不一定及时更新，与实测冲突时以实测为准。
