# 一手来源研究

## 流程

1. 明确研究问题、时间范围、需要回答的判断及交付形式；范围已清楚时直接开始。
2. 优先查找拥有该事实的来源：官方文档、规范、源代码、第一方 API、原始论文或原始数据。
3. 对关键结论交叉核验，记录发布日期与事件日期；区分来源直接支持的事实、合理推断和仍未知的信息。
4. 引用紧邻所支持的结论，并链接到具体页面、文档或论文，不引用搜索结果页。
5. 给出简洁结论、证据边界、冲突来源和仍需验证的问题。

仅在用户要求持久化时写 Markdown 文件：优先使用用户指定位置，其次遵循仓库现有约定。用户未授权子 agent 时由当前 agent 完成研究，不自行委派。

不要用二手综述替代可获得的一手来源；无法验证的说法应明确标注，而不是补成确定结论。
