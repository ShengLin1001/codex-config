# 通用学术表达与论证语料

本文件来自 [corpus-index.md](corpus-index.md) 中参考论文的跨文章模式，只提供可选择的写作工具，不代表 PJ 的个人偏好。优先跟随目标学科、期刊和稿件既有结构。

## 通用论证单元

默认使用最短的完整证据链：

1. 说明研究对象、条件或问题；
2. 给出图、表、数据、公式或引用；
3. 解释证据与结论之间的关系；
4. 给出不超过证据范围的结论或未解决问题。

缺少第 2 或第 3 步时，不用强化词掩盖证据缺口。

## Abstract

可按任务裁剪以下功能，不要求固定句数：

1. 对象及重要性；
2. 已知事实与具体空白；
3. 本文采用的方法；
4. 最重要的定量结果；
5. 机理或独立验证；
6. 有边界的意义。

常用短模式：

- Gap: `..., but the mechanism governing X remains unclear.`
- Purpose: `Here, we use X to determine Y.`
- Purpose: `In this study, X is employed to investigate Y.`
- Result: `Our results show that X changes from A to B under C.`
- Meaning: `These findings provide a basis for X.`

不要在结尾连续写两句泛化意义，也不要在摘要中引入正文没有证明的机理。

## Introduction

按“背景 → 已有证据 → 具体空白 → 本文问题与路线”推进：

- 领域背景必须用代表性研究和引用落地。
- 每个文献例子说明对象、方法和与本文问题的关系；不要只堆作者名单。
- 用 `However`、`but` 或 `remains` 明确尚未解决的具体问题。
- 研究问题与后文结果顺序一致。

短模式：

- `Previous studies established X under Y [refs].`
- `However, whether X controls Y under Z remains unresolved.`
- `Therefore, two questions arise. First, ... Second, ...`
- `To address these questions, we ...`
- `The remainder of this paper is organized as follows.`

路线图只在目标期刊或稿件需要时使用。

## Methods

- 一节只说明一种方法或一组直接相关设置。
- 参数同时给数值、单位、边界条件和必要引用。
- 定义输入、约束、允许松弛的自由度和输出量。
- 验证方法时给出比较对象和一致性依据。

短模式：

- `X was calculated using Y with a cutoff of Z.`
- `During relaxation, X was fixed, whereas Y was allowed to relax.`
- `The calculated X agrees with the reported value [ref], supporting the reliability of Y.`

## Results

每个结果段落使用“段首定位 → 定量证据 → 解释 → 段尾结论”：

- `Figure 3(d) shows X as a function of Y.`
- `As X decreases from A to B, Y decreases from C to D.`
- `In contrast, Z changes only slightly by E.`
- `This difference indicates that ...`
- `Therefore, X is the dominant factor under Y.`

比较多个材料、条件或 panel 时逐项覆盖，不用“similar trends”代替缺失数据。

## Discussion

Discussion 用于综合、解释、比较和界定，不用于突然改写结果：

1. 先重述需要解释的核心关系；
2. 将多个结果放入同一机理链；
3. 与已有研究比较；
4. 解释适用条件、限制和仍未确定的贡献；
5. 给出与正文一致的综合结论。

短模式：

- `Taken together, these results indicate that ...`
- `This behavior can be understood from ...`
- `Compared with X, Y differs because ...`
- `A possible origin is ..., although its contribution remains to be quantified.`
- `However, the present analysis is limited to X.`

若一种效应在正文被证明不足，Discussion 不得无新证据把它重新设为主因。

## Conclusion

- 按正文顺序概括研究问题、主要结果和关键数字。
- 区分热力学、动力学、实验验证和机理结论。
- 不引入新数据、新引用或新因果。
- 最后只保留一句与证据相称的应用或研究意义。

短模式：

- `In this work, we investigate X using Y.`
- `The results demonstrate that ...`
- `Specifically, X changes from A to B under C.`
- `These results provide guidance for ...`

## Figure captions

- 首句说明整张图展示什么。
- 按 `(a) ... (b) ...` 顺序覆盖 panel。
- 解释颜色、线型、符号、箭头、插图和统计量。
- 图注只描述图中内容；机理讨论留在正文。

## 使用限制

- 不复制参考论文的长句或整段文字。
- 不把 DFT、HRTEM、FCC/HCP 等领域词汇套到无关学科。
- 不机械套固定五段引言或固定七句摘要。
- 不因参考论文出现一次就把表达设为强制规则。
- 同一表达若与目标稿、目标期刊或个人偏好冲突，舍弃该表达。
