# 评价判据与章节骨架

评价时用来判断"这个说法的边界对不对""这一节缺了哪一环"。本文件只给边界和功能序列，不给可改写的句子——改写是 `p-article-polishing` 的活。

「标志表达」列是识别锚点，不是模板。目标稿的既有写法和目标期刊体例高于本表；命中不等于判错，还要看技术含义、搭配和上下文。

## 指出研究空白

不同表达对应不同类型的"未知"，不能互换。

| 空白类型 | 标志表达 | 语义边界 |
|---|---|---|
| 已研究 A，不了解 B | `little is known about` | 建立明确的已知—未知对照 |
| 文献中尚无报道 | `has not been reported` | 只在完成可靠检索后使用 |
| 领域基本未触及 | `remains unexplored` / `remains nearly unexplored` | `nearly` 表示已有少量相关工作 |
| 机理研究不足 | `remains insufficiently investigated` | 现象已有，机理证据不足 |
| 缺少实验证明 | `experimental evidence remains missing` | 理论或间接迹象已有，实验验证缺失 |
| 具体问题待答 | `remains unresolved` / `remains to be determined` | 本文能直接回应的问题 |
| 测量本身困难 | `remains an experimental challenge` | 空白来自方法或分辨率限制 |

比 `not well studied` 更准的是说清缺的是报道、知识、机理、实验验证还是测量能力。

本表是常见类型，不是穷举。归不进任何一类时照录作者实际的空白表述，只有当空白本身不具体时才算问题，不替作者选一类。

## 选择证据动词

这些动词不是文采替换，而是证据等级。

| 动词 | 成立所需的证据 |
|---|---|
| `show` | 数据、图或实验直接呈现 |
| `demonstrate` | 多项证据共同支持较强结论 |
| `reveal` | 揭示此前不可见的结构、关系或路径 |
| `indicate` | 数据支持该解释，但不是唯一证明 |
| `suggest` | 间接、模型依赖或仍有不确定性 |
| `confirm` | 独立手段验证前一结果 |

用 `demonstrate`、`confirm` 承载单一间接结果，是断言边界问题，不是措辞问题。`prove` 不作默认结果动词；同一句里堆 `may possibly be likely to` 是措辞问题。

## 比较、对照与逐项对应

| 关系 | 标志表达 | 成立条件 |
|---|---|---|
| 同句直接对照 | `whereas` | 两个分句结构严格平行 |
| 新句对照 | `In contrast,` | 前后结论较长，需独立成句 |
| 指定比较基准 | `Compared with` | 基准明确且比较维度一致 |
| 排除另一选择 | `rather than` | 数据能区分互斥路径或解释 |
| 判断主导因素 | `dominant over` | 已分别量化两个因素的贡献 |
| 一一对应 | `respectively` / `correspond to` | 项目数量和顺序完全一致 |

非时间关系的对比用 `whereas` 优于含糊的 `while`。`respectively` 救不了含糊的对应——数量或顺序对不齐时是对应关系本身的问题。

## 解释机理与因果

| 因果强度 | 标志表达 | 成立条件 |
|---|---|---|
| 仅相关 | `is associated with` | 只观察到同步变化或数值吻合 |
| 直接机理来源 | `stems from` | 有计算、实验或理论链支撑 |
| 可能起源 | `may arise from` | 存在多个候选来源 |
| 归因于已知因素 | `is attributed to` | 引用或既有模型支持该解释 |
| 普通因果 | `is due to` / `because of` | 因果已被单独验证，不只是相关 |
| 促进过程 | `facilitates` | 降低能垒或增加可达性 |
| 阻碍过程 | `hinders` | 抑制转变、输运或响应 |
| 分离贡献 | `solely corresponds to` | 控制变量足以隔离单一贡献 |

只有同步变化就写 `is due to`，是断言边界问题。

## 选择逻辑连接语

| 功能 | 连接词 | 使用条件 |
|---|---|---|
| 转折或限制 | `However,` | 后句修正、限制或反驳前句 |
| 句间对照 | `In contrast,` | 明确比较两个对象或方法 |
| 同句对照 | `whereas` | 两个平行分句 |
| 增加独立证据 | `Furthermore,` / `Moreover,` | 后句新增证据，不是同义重复 |
| 具体化 | `Specifically,` / `In particular,` | 后句给数字、条件或代表性案例 |
| 强化前述解释 | `Indeed,` | 后句直接验证前句，不只是继续叙述 |
| 局部综合 | `Overall,` | 汇总紧邻数据后给受限结论 |
| 真正更重要 | `More importantly,` | 后句在论证层级上确实更关键 |
| 结果反常 | `Interestingly,` / `Surprisingly,` | 结果相对基准或普遍预期确实反常，且不代替机理解释 |

同一段堆叠多个同功能连接词，报为行文问题。

## 限定判断强度

| 判断状态 | 标志表达 | 成立条件 |
|---|---|---|
| 较强概率判断 | `is likely to` | 多项迹象一致但未直接验证 |
| 较弱候选判断 | `might be` | 证据更弱或存在多个等价解释 |
| 防止过度解释 | `might be only a coincidence` | 数值吻合但变量并非严格对应 |
| 排除不足因素 | `cannot be explained by ... alone` | 定量结果已证明该因素不足 |
| 明确后续工作 | `needs further investigation` | 能指出缺少的具体模型或实验 |
| 保留未解问题 | `remains to be answered` | 结论尚不足以解释机理 |

## 给出有边界的意义

| 意义类型 | 标志表达 | 成立条件 |
|---|---|---|
| 开启研究路径 | `open up new ways to` | 方法或现象确实使新研究成为可能 |
| 奠定概念基础 | `provide a foundation for` | 本工作构成后续研究或操控的依据 |
| 给出实践指导 | `offer guidance for` | 结果可转化为设计、制备或实验选择 |
| 提供机制认识 | `provides insight into` | 主要贡献是理解而非直接应用 |

摘要或结论通常只保留一句意义。多于一句，或意义超出正文建立的范围，是断言边界问题。

## 识别模型腔

以下是模型写作的识别特征。命中只作待复核提示，**不自动判错**——目标稿原本就在用且用得准确时不报，报告方式见 [language-review.md](language-review.md)。

**零出现词**——LLM excess-vocabulary 清单中，在五篇材料科学、凝聚态与第一性原理参考论文里零出现的部分：

`delve, underscore, showcase, leverage, harness, foster, bolster, catalyze, unearth, illuminate, navigate, scrutinize, transcend, boast, embark, grapple, juxtapose, encompass, emphasize`；
`intricate, meticulous, pivotal, nuanced, multifaceted, groundbreaking, innovative, transformative, invaluable, commendable, renowned, exhaustive, actionable`；
`additionally, notably, seamlessly, profoundly, strategically, thoughtfully, undoubtedly, accurately`；
`realm, tapestry, testament, journey, milestone, ecosystem, prowess, essence, intricacy, utilization`；
`shed light on, deep dive, game changer, vital role, knowledge gap`。

清单**按词形严格生效，不外扩到同根词**：报的是句首的 `Additionally`（参考论文 0 次），`in addition`（7 次）和 `additional`（11 次）不报；报 `accurately`（0 次），`accurate`、`accuracy`（共 4 次）不报。同理只约束表中列出的那个词形。

**灰名单，缺确切技术所指才报**：`align`、`complex`、`surpass`、`unveil`、`necessitate`、`noteworthy`、`versatile`、`deeper`、`advancement`。这些在参考论文里出现过，`aligned lattice`、`complex oxide`、`energy landscape` 这类实指不报，用作泛化强调才报。

**标点**：破折号（`—`、`–`）插入解释、冒号在句中引出解释或列举，报待复核。这里说的是破折号不是连字符——术语构词里的 `-`（`FCC- and HCP-`、`low-SFE`、`out-of-plane`）是作者约定，不报；题目里的冒号、图注编号、比值和公式里的固定写法不报。

**不是禁用词**：`critical`、`crucial`、`fundamental`、`remarkable`、`universal`、`It is worth noting`。判据是有没有数字、引用或清楚逻辑支撑，有支撑就不报。

## 章节功能骨架

各章节的功能序列，用来反查稿件实际做到哪一步、缺哪一环。

**这是功能骨架不是模板。**稿型或目标期刊另有体例时以后者为准；缺环只在确实断了证据链时报告，不因为少一环就判错。

| 章节 | 功能序列 |
|---|---|
| Title | 体系或对象 → 核心发现或关键手段 → 必要的限定（材料、条件、方法） |
| Abstract | 对象与问题 → 具体空白 → 本文做了什么 → 最重要的定量结果 → 机理或独立验证 → 一句有边界的意义 |
| Introduction | 背景与代表性证据 → 明确空白 → 本文能回答的问题 → 方法与路线 |
| Methods | 框架或仪器 → 关键参数与近似 → 统一口径 → 可靠性验证 |
| Results（每小节） | 图/panel 定位 → 条件与定量趋势 → 基准或对照 → 与证据强度匹配的解释 → 段尾结论 |
| Discussion | 核心关系 → 多个结果的统一机理 → 与已有工作比较 → 候选来源及其证据强弱 → 限制与待验证部分 → 有边界的综合 |
| Conclusion | 对象与方法 → 按正文顺序概括主结果和关键数字 → 机理或验证结论 → 一句意义 |
| Figure caption | 首句说明整图功能 → 逐 panel 覆盖 → 解释颜色、线型、符号、箭头、插图、统计量 |

分章要点：

- **Title**：只包含正文真正支持的断言。描述型和结论型都可用，跟随目标期刊体例；题目里的冒号属于固定体例，不受正文标点规则约束。
- **Abstract**：意义句通常只有一句。多于一句，或在摘要里引入正文没有建立的数据、因果、应用，都是问题。
- **Introduction**：空白要说清缺的是哪一种，见本文件「指出研究空白」。文献例子要说明其对象、方法或结论与本文问题的关系。
- **Methods**：反复使用的方向、基准或条件应有一句统一口径。可靠性要有比较量和文献结果，不能只说方法可靠。
- **Discussion**：深化、统一并解释正文结果，不重复 Results 的数字。
- **Caption**：图注描述图里有什么，机理讨论留在正文。
